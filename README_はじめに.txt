# ポケログ PWA

iPhoneのSafariからホーム画面に追加して使うためのWebアプリ一式です。

## 含まれるファイル
- `index.html` : 対戦記録アプリ本体
- `manifest.webmanifest` : ホーム画面アプリとしての設定
- `sw.js` : オフライン起動用のキャッシュ設定
- `icons/` : アプリアイコン

## 重要：記録データについて
- 対戦記録はブラウザのローカル保存領域に保存されます。サーバーには送信しません。
- ブラウザのデータ消去や、別のURLへの移行で記録が見えなくなる可能性があります。
- アプリ内のJSON書き出しで定期的にバックアップしてください。
- このPWA版は、公開前に保存・再読み込み・JSON書き出し/読み込みをテストしてください。

## 公開方法の例：GitHub Pages
1. MacBookでGitHubにログイン（アカウントがなければ作成）します。
2. 新しいリポジトリを作成します。名前例：`pokelog`。
3. リポジトリにこのフォルダ内のファイルと`icons`フォルダをアップロードします（ZIPファイルそのものではなく、展開した中身）。
4. リポジトリの **Settings → Pages** を開きます。
5. **Build and deployment** で `Deploy from a branch` を選択します。
6. ブランチを `main`、フォルダを `/(root)` にして保存します。
7. 公開URLが表示されるまで待ち、そのURLをiPhoneのSafariで開きます。
8. Safariの共有ボタン → **ホーム画面に追加** を選びます。表示される場合は **Webアプリとして開く** を有効にして追加します。

## GitHub Pages利用時の注意
- HTML/JavaScriptなどのソースは、そのリポジトリを見られる人に公開されます。個人の対戦ログやJSONバックアップは絶対にリポジトリへアップロードしないでください。
- 対戦記録データはURLごとに別扱いです。公開URLを変更すると、以前の記録がそのまま表示されない場合があります。
- `sw.js`のキャッシュ更新が反映されるまで時間がかかる場合があります。更新時はCACHE_NAMEのバージョンを変更してください。
